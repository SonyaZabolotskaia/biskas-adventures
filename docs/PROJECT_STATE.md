Стоит в комнате и в портрете диалога. Проверено в Play Mode.

- Полный набор оригинальных ассетов-заглушек (12.10.2026): Бискас и Врискас (анимированные части), фон лаборатории, стол, вентиляция, пропуск, тайник в 4 состояниях, ключ, дверь (2 состояния), облако памяти и 4 иконки, эффекты. Генераторы: `Tools/ArtGen/characters.py`, `room.py`.
- Анимации: открытие тайника (створка на петле) → ключ поднимается со вспышкой → летит по дуге в ячейку инвентаря (ввод заблокирован на ~1,5 с, Бискас подпрыгивает); «Память Бискаса» — пузырьки и облако-мысль, 4 шага с картинкой и подписью, Бискас объясняет (печатающийся текст, говорит; касание дописывает текст). Шаги воспоминания — в JSON (`memory.steps`).
- Бискас стоит в комнате (глаза светятся в режиме памяти) и в левом портрете диалога. Проверено в Play Mode.

- Взаимодействие с предметами (12.10.2026): по касанию Бискас идёт вприпрыжку к предмету (под настенный тайник или сбоку от пропуска/двери), разворачивается, тянется к нему, и только тогда применяется действие. Результат анимирован: «появление» — предмет «выпрыгивает» со свечением и искрой (осмотр пропуска, найден тайник, открыта дверь), ключ — створка, подъём, полёт в инвентарь; «ничего нет» — облачко пыли, пузырь «?» и Бискас качает головой. В X-Ray смотрит Врискас — Бискас не подходит. Ввод в комнате заблокирован на время подхода/анимации; финальный экран — через 1,1 с после открытия двери. Код: `CharacterAnimator` (MoveTo/Reach/ShakeHead), `InteractionFx`, `EpisodeController`.

## Текущая задача

Android-сборка и проверка на телефоне (заблокировано: нет модуля Android Build Support).

## Известные ошибки / риски

- На телефоне не запускалось (нет Android-модуля); фон/SafeArea/вырез проверены только кодом.
- Предупреждение Unity об устаревании Input Manager; переход на Input System — отдельная задача.
- Шрифт-заглушка LegacyRuntime; нужен шрифт с кириллицей и лицензией.
- Звука пока нет (пауза AudioListener предусмотрена).

## Следующий шаг

1. Пользователь: установить Android Build Support (+ OpenJDK, SDK & NDK) для 6000.3.10f1.
2. Biskas → Собрать Android APK (development), установить на телефон, пройти чек-лист `docs/QA.md`.
3. Проверить Device Simulator (вырез, 20:9).
4. Утвердить референс дизайна Врискаса и заменить PNG-части; затем Бискас (та же схема частей), фон и предметы по `docs/ASSET_PLAN.md`.

## Архитектура (кратко)

```
EpisodeController (MonoBehaviour, ссылки в сцене)
 ├─ EpisodeLogic  ← TapObject / ToggleMode / ToggleSelectItem → ActionResult(messageId, stateChanged, event)
 ├─ DialogueRunner ← узлы из JSON, условия, эффекты, взаимоисключающий выбор
 ├─ SaveStore     ← persistentDataPath/episode1.save
 └─ Views: RoomHotspot×3, InventoryView, MemoryView, DialogueView, MenuView, EndView, SafeAreaFitter
```

Сюжетные ID: предметы `pass/cache/door`, предмет `key_lab`, флаги `pass_inspected, memory_seen, dialogue_done, trust_vriskas | rely_on_self, cache_revealed, key_taken, door_opened`. Значения не менять — они в сохранениях.
