## Ручная проверка в редакторе (чек-лист)

1. Biskas → Создать или открыть сцену эпизода; Console без ошибок.
2. Biskas → Самопроверка логики и сцены → «Все проверки пройдены».
3. Play: «Начать» → коснуться пропуска → «Память Бискаса» → пропуск → воспоминание → «Вернуться» → диалог, выбрать вариант → «Зрение Врискаса» → зелёная «Пустота за панелью?» → коснуться → коснуться тайника ещё раз → ключ в инвентаре → коснуться ключа → дверь → «Эпизод завершён».
4. Быстрые двойные клики по тайнику, «Далее», «Вернуться», выбору.
5. Остановить Play после подсказки и после ключа → Play → «Продолжить» → состояние на месте.
6. После завершения → Play → сразу экран завершения; «Новая игра» → начало.
7. Испортить файл (`%USERPROFILE%\AppData\LocalLow\BiskasFan\Бискас_ Эхо памяти\episode1.save` — путь печатается `Application.persistentDataPath`) → Play → сообщение и только «Новая игра».
8. Device Simulator: устройство с вырезом в landscape — кнопки не под вырезом.

## Известные риски

- Шрифт: встроенный `LegacyRuntime.ttf` (динамический, кириллица берётся из системных шрифтов). На Android обычно работает, но не проверено; для релиза нужен свой шрифт с кириллицей и лицензией.
- `Packages/manifest.json` написан вручную: версия ugui 2.0.0 взята из встроенных пакетов установленного редактора; при первом открытии Unity может дописать зависимости.
- Если Unity создаст ProjectSettings с Active Input Handling = Input System, `ProjectSetup` переключит на «Both» и попросит перезапуск.
