# Лор: исходная база

Это проект самостоятельной фанатской истории. Весь сюжет лабораторной комнаты придуман для игры. Привязка к хронологии и дизайн конкретных версий персонажей пока не утверждены.

| Сведение | Статус | Источник |
|---|---|---|
| Бискас видит прошлое через прикосновение к предмету/существу | Фан-вики; сверить с авторской серией | https://vselennaya-biskasa.fandom.com/ru/wiki/Бискac |
| Врискас — симбиот, связан с внутренним миром Бискаса; обладает ночным зрением и X-Ray | Фан-вики; сверить период истории | https://vselennaya-biskasa.fandom.com/ru/wiki/Врискас |
| Впискас поглощает способности | Фан-вики; для первой комнаты не требуется | https://vselennaya-biskasa.fandom.com/ru/wiki/Впискас |
| Бессмертное наследие рассказывает о коте, ставшем человеком | Описание авторского выпуска, видео полностью не просмотрено | https://www.youtube.com/watch?v=N7EaF6x36IQ |
| Чужие лица использует сюжет с выбором | Название и описание авторского выпуска | https://www.youtube.com/watch?v=Hkd1xfnCrTo |
| Пропуск, скрытый ключ, закрытый сектор лаборатории | Допущение игры | Дизайн первого эпизода |
| Кнопки переключения способностей, подсказка как условие получения ключа | Допущение игры | Ограничения ради загадки |

Не переносить неподтверждённые подробности поздних сезонов в первый эпизод. Здесь не утверждается, что лаборатория является конкретной канонической лабораторией.
